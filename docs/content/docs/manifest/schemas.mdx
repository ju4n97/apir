# schema

The `schema` block defines data models used for validating incoming request bodies and masking outbound responses.

```hcl
schema "User" {
  description = "Application user profile"

  field "id" {
    type     = "integer"
    required = true
  }

  field "email" {
    type     = "string"
    format   = "email"
    required = true
  }

  field "role" {
    type    = "string"
    default = "member"
    enum    = ["admin", "member", "viewer"]
  }

  field "age" {
    type = "integer"
    min  = 18
    max  = 120
  }
}
```

## Field constraints

| Attribute     | Type     | Applicable types    | Description                                                 |
| :------------ | :------- | :------------------ | :---------------------------------------------------------- |
| `type`        | `string` | all                 | `string`, `integer`, `number`, `boolean`, `array`, `object` |
| `format`      | `string` | `string`            | Built-in semantic format check                              |
| `required`    | `bool`   | all                 | Returns HTTP 422 if missing or null                         |
| `default`     | `any`    | all                 | Value injected if the key isn't provided                    |
| `description` | `string` | all                 | Field summary exported to OpenAPI documentation             |
| `min`         | `number` | `integer`, `number` | Minimum numeric value, inclusive                            |
| `max`         | `number` | `integer`, `number` | Maximum numeric value, inclusive                            |
| `min_length`  | `int`    | `string`            | Minimum string character length                             |
| `max_length`  | `int`    | `string`            | Maximum string character length                             |
| `enum`        | `list`   | `string`            | Allowed string values                                       |
