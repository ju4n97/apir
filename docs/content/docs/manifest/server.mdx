# server

The `server` block configures transport limits, timeouts, and listener ports.

```hcl
server {
  host          = "0.0.0.0"
  port          = 8080
  read_timeout  = "15s"
  write_timeout = "30s"
  max_body_size = "25MB"
}
```

## Attributes

All attributes are optional and use safe production defaults:

| Attribute       | Type       | Default       | Description                                                |
| :-------------- | :--------- | :------------ | :--------------------------------------------------------- |
| `host`          | `string`   | `"127.0.0.1"` | IP address to bind                                         |
| `port`          | `int`      | `8080`        | TCP port                                                   |
| `read_timeout`  | `Duration` | `"15s"`       | Maximum duration allowed to read incoming requests         |
| `write_timeout` | `Duration` | `"15s"`       | Maximum duration allowed to stream responses               |
| `max_body_size` | `ByteSize` | `"10MB"`      | Payloads larger than this limit are rejected with HTTP 413 |

## Configuration units

You don't need to calculate raw numbers by hand:

- **`Duration`**: Standard Go duration strings like `500ms`, `15s`, `10m`, or `1h30m`.
- **`ByteSize`**: Human readable sizes like `512B`, `10KB`, `10KiB`, `25MB`, `1GB`, or `1GiB`.
