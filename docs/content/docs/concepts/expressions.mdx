# Expressions and built-ins

Dynamic values in `args`, `when`, `headers`, and `body` evaluate at request time using native HashiCorp HCL expressions.

## Operators

| Category       | Operator             | Example                                                |
| :------------- | :------------------- | :----------------------------------------------------- |
| **Equality**   | `==`, `!=`           | `steps.find_user.rows_affected == 0`                   |
| **Relational** | `<`, `<=`, `>`, `>=` | `ctx.request.path.id > 100`                            |
| **Logical**    | `&&`, `\|\|`, `!`    | `!steps.cache.found && ctx.request.body.active`        |
| **Ternary**    | `? :`                | `steps.cache.found ? steps.cache.value : steps.db.row` |
| **Arithmetic** | `+`, `-`, `*`, `/`   | `ctx.request.body.price * 1.15`                        |

## Built-in functions

### `now()`

Returns the current UTC timestamp formatted as an RFC 3339 string:

```hcl
respond {
  status = 200
  body = {
    updated_at = now()
  }
}
```

### `uuid()`

Generates a cryptographically secure RFC 4122 UUID v4 string:

```hcl
step "sql" "create_item" {
  connection = "main"
  query      = "INSERT INTO items (id, name) VALUES (@id, @name)"
  args = {
    id   = uuid()
    name = ctx.request.body.name
  }
}
```

### `problem(status, detail)`

Constructs an RFC 9457 Problem Details object, automatically inferring the title and error type URN:

```hcl
respond {
  when   = steps.check.rows_affected == 0
  status = 404
  body   = problem(404, "Requested resource does not exist")
}
```

### `upper(str)` and `lower(str)`

Transforms string casing:

```hcl
step "sql" "lookup" {
  connection = "main"
  query      = "SELECT * FROM accounts WHERE code = @code"
  args = {
    code = upper(ctx.request.query.code)
  }
}
```
